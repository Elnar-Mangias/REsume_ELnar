# Резюме — Исабеков Эльнар

Одностраничное резюме на React + Vite с адаптивным дизайном и кнопкой печати / сохранения в PDF.

## Запуск локально

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовый сайт создаётся в `dist/`.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки (не сам ZIP).
2. Убедись, что основная ветка называется `main`.
3. В репозитории открой **Settings → Pages** и в разделе **Build and deployment** выбери **GitHub Actions**.
4. Отправь изменения в `main`. Workflow `.github/workflows/deploy.yml` соберёт сайт и опубликует его.

`base: './'` в `vite.config.js` позволяет использовать относительные пути к ресурсам на GitHub Pages.

## Где менять данные

- `src/data.js` — имя, образование и контакты.
- `src/App.jsx` — секции страницы.
- `src/styles.css` — внешний вид и адаптация для мобильных устройств.
